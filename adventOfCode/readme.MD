# Advent of Code Solutions

## Overview
These are solutions hacked together to solve the yearly Advent of Code puzzles. I originally did these in C# using LinqPad but for the last few years I've switched to Python. Also I've gone back and started doing the earlier years in Python. 

## Getting Started

I have the inputs in a private repo. I recommend you create a private repo or a location on your personal network with the same structure as the solution files. This makes it easy to find the inputs for each puzzle. Then create an Environment variable with the path to the input files: 

Linux/macOS (bash/zsh):

```bash
export AOC_INPUTS_DIR="$HOME/code/aoc-inputs"
```

Put that in ~/.bashrc or ~/.zshrc.

Windows PowerShell (user-level):
```powershell
setx AOC_INPUTS_DIR "C:\code\aoc-inputs"
```

(Open a new terminal after.)
